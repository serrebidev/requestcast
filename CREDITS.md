# Credits

RequestCast searches for music, downloads it, tags it properly, and files it into a library, either a folder on your own machine or an AzuraCast station's request playlist.

Third-party projects it downloads and uses on first run:

- yt-dlp
- ffmpeg
- Deno
- musicdl (for the optional musicdl platforms)
- Soulseek peers, YouTube, and Deezer as sources
- AzuraCast as a destination library

Those projects belong to their own authors. RequestCast only wires them together.
