Add music

Search by name or paste a YouTube, Deezer, or other supported music link. RequestCast keeps the best available audio and adds it to the request library. Artists and YouTube channels can be opened to pick individual releases, albums, or videos.

Each source and result type returns up to this many, so "Everything" across both sources brings back several times this number. Larger searches take longer.

Upload a music list or playlist

Upload TXT, XLSX, or PDF. Use Artist - Title for songs, or one artist or URL per line. Tables use the first two columns as artist and title.

Existing playlists work too: M3U, M3U8, PLS, XSPF, WPL, ASX, CUE, and foobar2000 FPL. RequestCast reads the artist and title each playlist names and fetches those tracks; it does not need the original files.

Only affects artist-only lines. Large lists can queue thousands of tracks.

Limit: 64 MB and 250,000 unique entries, so a whole library list fits. A file that size takes a few seconds to index and a long time to download.
